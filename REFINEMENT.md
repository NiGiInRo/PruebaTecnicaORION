# Actividad de Refinamiento
Esta actividad hace parte integral de la evaluación.
El backlog entregado representa una visión inicial del producto y deliberadamente contiene información limitada.
Antes de iniciar el desarrollo se espera que el candidato realice un ejercicio de análisis funcional y técnico.
---

# Objetivo
Evaluar la capacidad para:
- Interpretar requerimientos.
- Detectar vacíos funcionales.
- Identificar riesgos.
- Modelar entidades de negocio.
- Descomponer trabajo.
- Priorizar funcionalidades.
- Justificar decisiones técnicas.
---

# Actividad
Crear un archivo denominado:
```text
BACKLOG_REFINED.md
```
---
# Instrucciones
Para cada historia de usuario:
## 1. Análisis
Identifique:
- Ambigüedades.
- Dependencias.
- Riesgos.
- Supuestos.
---
## 2. Refinamiento
Defina:
- Entidades involucradas.
- Reglas de negocio.
- Estados.
- Relaciones.
- Flujo funcional.
---
## 3. Descomposición Técnica
Genere las actividades necesarias para implementar la funcionalidad.
Por ejemplo:
- Backend.
- Frontend.
- Persistencia.
- Seguridad.
- Testing.
- Docker.
---
## 4. Estimación
Asigne una estimación para cada actividad.
Puede utilizar:
```text
XS
S
M
L
XL
```
o
```text
Horas
```
---
## 5. Priorización
Identifique:
- MVP.
- Funcionalidades opcionales.
- Mejoras futuras.
---
## 6. Justificación
Explique:
- Qué actividades agregó.
- Qué actividades eliminó.
- Qué decisiones tomó.
- Qué riesgos identificó.
---
# Preguntas de Reflexión
Durante el refinamiento considere las siguientes preguntas:
- ¿Qué entidades son necesarias?
- ¿Qué estados debería tener una Orden de Trabajo?
- ¿Qué información requiere una Cuadrilla?
- ¿Cómo se controla el consumo de inventario?
- ¿Cómo se relacionan los activos con las actividades de mantenimiento?
- ¿Qué indicadores son importantes para un supervisor?
---
# Resultado Esperado
El resultado de esta actividad deberá quedar documentado en:
```text
BACKLOG_REFINED.md
```
---
# Criterios de Evaluación
Además del software desarrollado se evaluará:
- Capacidad analítica.
- Comprensión del dominio.
- Diseño funcional.
- Organización.
- Claridad de comunicación.
- Planeación técnica.
---

# Importante
No existe una respuesta única correcta.
Se valorará especialmente la capacidad para transformar necesidades de negocio en actividades técnicas ejecutables y justificadas.
